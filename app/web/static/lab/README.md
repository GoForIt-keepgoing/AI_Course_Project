## 一、快速启动（推荐）

需要 **Node.js 18+**（本机已就绪）。

```powershell
cd "D:\大三\小白学人工智能\小学英语AI助教-完整版"
node server.js
# 浏览器打开 http://localhost:8080
```

> 用 `http://localhost` 打开才能：
> - 使用**口语录音**（浏览器要求安全上下文）；
> - 让数字人走**真实大模型自由对话**；
> - 使用「动态回答」「AI 优化提示词」等大模型增强能力。

## 二、启用大模型

数字人默认走“脚本模式”。配置 DeepSeek API Key 后自动切换为 **AI 自由对话**（右上角徽章变绿 `● AI 自由对话`）。

```powershell
$env:DEEPSEEK_API_KEY="sk-你的key"
node server.js
```

或在同目录新建 `config.json`：

```json
{ "apiKey": "sk-你的key" }
```

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 空 | 必填才能启用 AI |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | 兼容 OpenAI 的接口地址 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | 模型名 |
| `PORT` | `8080` | 服务端口 |

## 四、动态能力说明

- **分层练习**：切换「题型」会即时从题库重新抽题；L1/L2/L3 各档按难度抽取；选择题可点选，填空/连词成句可输入，批改后按真实作答计分并给出错因。
- **教学设计**：可上传 / 粘贴课本单元内容，自动抽取词汇与句型，生成对应的教学案例；配置 Key 后由大模型生成结构化教案。
- **写作反馈**：读取你编辑的作文原文，实时检测大小写、主语重复、标点、表达单调等问题，生成批注与评分。
- **资源生成**：情境对话、阅读、复述可切换篇目；课堂互动里随机点名后，由老师**手动输入学生回答**，系统给出星级与建议。
- **思维导图**：节点可拖动、添加子节点、重命名、删除、自动整理，并导出 SVG。
- **提示词教练**：模板一键填充，生成结构化提示词；配置 Key 后可让模型润色，一键复制。
- **游戏**：每局随机洗牌、随机出词、限时计分。
- **单词跳跳岛**：横版跳跃收集，← → 移动、空格/↑ 跳跃；水果标注**英文单词**，收集与目标单词一致的水果；3 关、3 颗爱心、60 秒倒计时，支持暂停/继续。

## 七、常见问题

**Q：直接双击 index.html 可以吗？**
可以打开，但录音不可用（浏览器安全限制），数字人只能脚本模式，「动态回答」也不走大模型。建议 `node server.js`。

**Q：数字人说话没声音？**
浏览器需允许播放；点击「开始上课」产生用户交互后即可。若无英文语音包，可在系统“语言”设置中安装英语语音。

**Q：录音没反应？**
确认用 `http://localhost:8080` 打开并允许麦克风权限；语音识别依赖 Chrome/Edge 内置能力。

**Q：AI 优化提示词 / 动态回答不可用？**
需要在启动前配置 `DEEPSEEK_API_KEY`（或 `config.json`）。
