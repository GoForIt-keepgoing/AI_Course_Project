# 交付清单

本目录对应《AI4En 课程大作业综合说明》2.3 的统一交付清单。

## 1. 可运行应用

| 内容 | 位置 | 检查方式 |
| --- | --- | --- |
| 源码 | app/（后端）+ app/web/（前端） | 阅读 README 第 3 节目录结构 |
| 依赖与配置示例 | requirements.txt、config.example.env | 运行零第三方依赖；模型配置见 README 第 6 节 |
| 启动说明 | README.md 第 1 节、启动演示.bat | 双击启动后打开 http://127.0.0.1:8848/ |
| 虚拟账号与演示数据 | app/data/ai4en.db（首次启动生成） | 用 README 账号表登录三种角色 |
| 主流程可进入 | 教师工作台 → 课例 → 6 个页签 | 按 README 第 2 节 8 分钟路径走一遍 |
| 拓展工具（工作台内） | 登录后左侧栏“拓展”（`/#/studio`） | 游戏工坊、水果线索卡、游戏闯关、数字人、思维导图；顶栏与主应用一致 |
| 独立入口（备用） | `/static/workshop/index.html`、`/static/lab/` | 投屏或换设备时新窗口打开；与工作台加载同一套主题 |
| 答辩演示页 | `/static/defense/index.html` | 10 页 HTML 展示，可全屏、可打印 |
