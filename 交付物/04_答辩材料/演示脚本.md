> 若现场网络受限：系统不需要联网，模型未配置时按“示例内容”演示，不声称是真实模型输出。

## 备用动作（时间有余或评委要求）

1. 新建课例：填三个必填项 → 系统提示缺目标词句 → 补全 → 生成教案。
2. 直接发布未审核课例 → 提示“课例尚未审核通过”。
3. 勾选典型错题 → “组成复习练习” → 在任务列表看到新草稿。
4. 打开“使用指南” → 复制提示词 → 打印操作卡。

## 演示前检查清单

- [ ] 服务已启动，端口与本机一致（默认 8848）
- [ ] 教师窗口已登录 t_wang；学生窗口已登录 s_zhang；家长窗口已登录 p_zhang
- [ ] 教案处于“已审核”，任务处于“进行中”，张小明为“已订正”
- [ ] PPTX 与 PDF 能在演示电脑上实际打开（提前试一次）
- [ ] 若已重置数据，确认任务里仍有 4 条作答

## 常见追问与回答

- **“这是 AI 生成的吗？”** 演示环境未配置模型，生成内容标记为“示例内容”；配置 AI4EN_LLM_ 开头的环境变量后，同一入口会调用真实模型，失败会保留草稿并记录日志。
- **“学生能不能看到答案？”** 不能。任务发布冻结答案快照，学生接口统一剥离答案与解析字段，答案页仅教师可打开。
- **“改了教案，已发布作业会变吗？”** 不会。任务保存了发布快照；要改题请复制成新任务。
- **“为什么不用 Vue / FastAPI？”** 课程允许沿用现有工程；本次选择零依赖实现，保证任何装有 Python 的机器双击即可运行，评审无需安装环境。业务规则集中在 api.py，换成 FastAPI 不影响数据结构。
