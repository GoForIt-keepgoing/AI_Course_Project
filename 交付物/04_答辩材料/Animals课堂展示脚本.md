# Animals 动物探险课 · 8 分钟展示脚本

打开 [答辩页](http://127.0.0.1:8848/static/defense/)、[课堂投屏](http://127.0.0.1:8848/static/classroom/) 和 [教学工作台](http://127.0.0.1:8848/)。提前准备教师、学生和家长的独立登录窗口。首次启动加载的是虚拟演示班级。

彩排时在展示电脑打开 [Animals 课件](../01_同一课例成果包/Animals_课件.pptx) 和 [Animals 教案](../01_同一课例成果包/Animals_教案.pdf)，核对版式并保留窗口。第 8 页可快速指出教师 60 分钟培训材料与操作卡的位置。

| 时间 | 展示与操作 | 可见结果 |
| --- | --- | --- |
| 0:00–0:50 | 展示第 1–3 页，介绍三年级 Animals 的四个词与问答句型。 | 游戏、课件、任务与评价对齐同一节课。 |
| 0:50–2:00 | 教师打开 Animals → 教案备课，改一个环节的检查方式，保存并重开核对，再审核。打开课件资源，展示六页预览、PPTX 导出和词卡。 | 现场可编辑、可保存，课件可导出。 |
| 2:00–3:50 | 从 Animals → 课堂活动打开投屏，完成四组配对并重开。切换 Lily，投屏读出 “What’s this?”，输入 “It’s a cat.”。换狗图请听众口头回答。 | 原版玩法服务词汇操练，数字人示范问答；教师可继续组织同伴操练。 |
| 3:50–5:00 | 回到练习与小测，展示两种支架。在任务页预览并发布已审核课例的新任务。 | 本次题目及答案被冻结，学生端只显示作答内容。 |
| 5:00–6:00 | 切学生窗口，打开新任务并提交，表达题故意输入 “It’s a cta.”。 | 学生看到本人提交状态。 |
| 6:00–7:25 | 教师在结果与日志打开作答，复核反馈，确认“请检查字母顺序”。学生窗口刷新后按提示订正为 “It’s a cat.”。展示原作和订正。 | 教师确认才公开，订正保留原作。 |
| 7:25–8:00 | 查看提交率、观察记录与教学日志。切家长窗口查看已确认反馈，收回到第 9–10 页。 | 日志可根据本次记录调整下节课，家长只读。 |

如果现场时间紧，发布和提交后可用内置的已订正样例展示原作与订正对照。若现场没有可用语音，读屏幕上的问题并用键盘输入。
