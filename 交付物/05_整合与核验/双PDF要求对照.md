# 两份 PDF 的实现对照

课程综合说明提供课程验收范围和参考 PRD。工作坊网站介绍说明另一个已有项目的交互与使用条件。整合后的答辩沿用课程的三年级 Animals 作为师生家长主线，并保留工作坊中的四年级水果购物、动物猜谜和校园生活等培训材料。培训案例与正式课例只有经教师选择并保存的匹配词卡会发生数据交接。

依据为 [课程大作业综合说明](../../参考资料/AI4En_课程大作业综合说明.pdf) 第 1–10 页，以及 [工作坊网站介绍](../../参考资料/AI英语教学工作坊_网站介绍.pdf) 第 1–3 页。下表的实现说明用于定位功能与已知缺口。现场测试证据见 [本次验证](本次验证.md)。

## 课程 R1–R5

| 要求 | 在哪里演示 | 完成范围与边界 |
| --- | --- | --- |
| R1 教学设计 | Animals → 教案备课 → 保存、重开、审核；教案打印 | 教学条件、目标、五环节及时间、检查方式、课后安排可保存；目标与流程可单独重新生成，其他已编辑内容保留；词表以外的英文词在“内容检查”里提示，由教师决定替换或保留。现场测试见本次验证。 |
| R2 练习支持 | Animals → 练习与小测 → 切换「有句架」「给关键词」 | 围绕相同词句目标与表达题调整支架，教师选择；学生接口只返回本次选用的那一种支架，不给学生贴固定等级。 |
| R3 过程反馈 | 学生作答 → 教师确认反馈 → 学生一次订正 → 批改页对照 | 首次作答、确认反馈及订正可查看；结果页可记录“同目标换素材”的独立运用检查（独立完成 / 需要提示 / 需要帮助 + 一条观察意见），记录只对教师可见。 |
| R4 命题评价 | 七题学生卷、独立答案页、题库与批改 | 包括 4 道选择、2 道填空、1 道表达，教师核对答案与评价要点。学生端只展示允许公开的题目和反馈。 |
| R5 资源与活动 | 六页课件、词卡与任务卡、配对和排序 | 有可编辑 PPTX 导出及打印视图。新增工作坊配对词卡到课堂活动编辑草稿的入口；工作坊神秘线索卡作为另一种独立 HTML 游戏使用。 |

## 参考功能 F01–F09

| 编号 | 可看功能 | 仍需现场确认或未完成 |
| --- | --- | --- |
| F01 课例与教案 | 教学条件、示例草稿、编辑保存、复制、审核、目标/流程单独重生成 | 词表越界提示属于提醒，不是课程标准判定，最终由教师核对。 |
| F02 课件与资源 | 固定模板、逐页编辑、PPTX 导出、A4 词卡和任务卡 | 复杂版式、个性化图片与大段文字的适配依赖教师编辑。答辩前在现场电脑上打开导出文件检查排版。 |
| F03 课堂活动 | 教师端配对、排序、投屏、重玩；工作坊配对、线索卡和离线导出；口头问答与独立运用可在结果页留一条观察记录 | 观察记录是教师手工登记，系统不自动判定学生能力。投屏结果不计作学生个人成绩。 |
| F04 练习与小测 | 七题示例、题目编辑、两种支架、独立答案 | 内容与语言的最终评价由教师确认。 |
| F05 任务与作答 | 任务草稿、学生预览、发布快照、本人作答、阻断重复提交、超过截止时间拒绝提交 | 到期不会自动结束任务，仍需教师手动结束；未实现纸面或课堂代录与来源登记（只有教师观察记录）。 |
| F06 反馈与订正 | 客观题规则判定、开放题草稿、教师确认、一次订正、独立运用检查记录 | 独立检查是教师手工登记，不做自动测评。 |
| F07 结果与日志 | 已交与缺交、单题错误、待复核、错题练习草稿、听写答题纸与错词登记、三段式日志 | 听写错词只与错题清单并列展示，尚未自动并入组卷；纸面答题的代录未实现。 |
| F08 家长查看 | 虚拟家长账号只读查看绑定孩子的任务及已确认反馈 | 适用范围为本机虚拟账号和绑定数据。 |
| F09 指南与案例 | 原应用操作卡、提示词、60 分钟培训流程；同站工作坊和培训演示 | 60 分钟是课程要求下的实操方案，工作坊原版 20 页演示可用于约 40–45 分钟培训。两者均为计划时长，真实教师试用和学习效果没有验证证据。 |

## 工作坊网站介绍

| 来源位置 | 可看内容 | 保存与使用范围 |
| --- | --- | --- |
| 第 1–2 页，找茬侦探 | 选择预设材料中的问题，核对理由、参考改法并保存教师修改稿 | 自由文本由教师判断。 |
| 第 2 页，提示词修理铺 | 补充教学目标、学情、时间、分组、设备和输出格式，实时组装提示词，复制或存入背包 | 页面内的比较输出为预设示例。真正生成教学内容可由教师另用配置好的工具完成。 |
| 第 2 页，英语游戏工坊 | 编辑单词配对或神秘线索卡，预览、课堂展示、独立 HTML 下载 | Animals 答辩词卡可由教师载入课堂活动编辑草稿。其余游戏仍可用工作坊的投屏与离线文件。 |
| 第 3 页，资源与教程 | 六类教学方法、完整水果购物案例、四个外部工具入口与示例 | 教程页面保留原有公开信息核验日期。账号、收费、额度和外网工具实际可用性需以官方页面为准。 |
| 第 3 页，培训演示 | 原有 20 页 HTML 演示、讲师备注、键盘翻页、跳转、全屏、打印和实操返回 | [工作坊培训入口](http://127.0.0.1:8848/static/workshop/index.html#slides)。答辩入口另有整合版展示。 |
| 第 3 页，教学背包 | 当前浏览器内保存、编辑、重命名、下载、备份导入导出 | 浏览器和地址决定存储范围。活动载入后需在教师端核对并手动保存，课例数据由后端保管。 |

## 证据边界

默认运行不配置真实模型，教学助手按界面标签区分示例、规则与教师操作。后端保留可选模型接口配置。课堂答辩只展示实际完成的示例路径与失败处理，真实模型调用的结果以本次验证记录为准。演示数据全部为课程样例；系统没有真实学生长期表现或成绩提升的试用证据。
