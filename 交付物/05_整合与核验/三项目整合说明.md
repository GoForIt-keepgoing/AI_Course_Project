# 三个项目怎么合成一个作品

答辩时最容易被问的一句是：“这不是三个网站吗？”这一页说明**功能怎么合、外观怎么统一、数据边界在哪**。

## 1. 一个外壳，五个功能

登录后只有一套侧栏 + 顶栏：**工作台 · 拓展 · 使用指南**（学生、家长同样有侧栏与顶栏）。三个来源的功能被收进同一个外壳：

| 来源 | 现在放在哪 | 打开方式 | 数据放在哪 |
| --- | --- | --- | --- |
| 小白大作业（教学助手） | 主应用：课例、教案、课件、课堂活动、练习、任务、作答、反馈、订正、日志、家长 | 工作台 | SQLite（`app/data/ai4en.db`），学生作答与反馈是唯一事实来源 |
| dist（AI 英语教学工作坊） | 拓展 → **游戏工坊**、**水果线索卡**；培训演示仍可从工作坊进入 | 工作台内嵌，侧栏与顶栏不变 | 浏览器 localStorage（教学背包）；选中的词卡经教师确认后才进入课例草稿 |
| 小学英语AI助教-完整版 | 拓展 → **游戏闯关**、**数字人对话**、**思维导图** | 工作台内嵌 | 演示数据在 `data.js`；模型调用走后端 `/api/chat` |

“新窗口打开”只作为投屏或换设备的备用，不再是主要入口。

**只放不重复的能力。** 完整版自带的教学设计、分层练习、学情看板与主应用重叠，不放进“拓展”，避免两套功能各说各话；工作坊的找茬侦探与提示词修理铺属于教师培训，放在“使用指南”的入口里。拓展只保留主应用没有的三类：做游戏、玩闯关、数字人与思维导图。

## 2. 外观怎么统一

不是靠“看起来差不多”，而是把三套界面接在同一组设计变量上：

- `app/web/static/theme/ai4en-bridge.css` 把工作坊的 `--cream/--ink/--teal/--line/--radius` 与完整版的 `--bg/--surface/--primary/--sidebar/--shadow` 映射到教学助手的浅绿主色（#3f8f68）、淡绿背景（#f4faf6）、14px 圆角和同一套字体。
- 内嵌页用 `?embed=1` 隐藏工作坊的站点页头与完整版的侧边栏、顶栏，只保留内容区，所以看到的始终是 AI4En 的侧栏与顶栏。
- 按钮、卡片、标签、表格沿用主应用 `style.css` 的组件；两套模块原有的交互和快捷键不变。
- 独立打开 `/static/workshop/` 或 `/static/lab/` 时也会加载同一份桥接样式，不会突然换一个品牌。

## 3. 三个项目为什么都要留

- **主应用回答“这节课怎么教、学生交了什么、老师怎么反馈”**，必须有账号、权限、数据库和可追溯的作答记录。
- **工作坊回答“教师怎么学会用 AI、怎么把材料做成活动”**，成果是教师自己的背包，不该写进班级数据库。
- **完整版回答“课堂还能怎么玩”**，游戏、数字人、思维导图是同一课例的延伸演示，不承担真实班级数据。

三者用**同一套 Animals 词句**（cat / dog / panda / frog；What's this? — It's a …）串起来。

## 4. 现场怎么走（不增加时长）

主线仍在主应用里走完“备课 → 发布 → 提交 → 反馈 → 订正 → 复盘”。拓展只在需要时点开，各 20–40 秒：

1. 左侧栏 **拓展 → 游戏工坊**：载入 Animals 词卡，改一个释义，更新预览，课堂展示。
2. **拓展 → 水果线索卡**：逐条线索猜水果，演示“同一模板换素材”。
3. **拓展 → 游戏闯关**：任选一关（连词成句 / 配对 / 翻牌 / 打地鼠 / 跳跳岛）。
4. **拓展 → 数字人**：未配 Key 时是脚本对话，右上角写“演示模式”。
5. **拓展 → 思维导图**：拖动两个节点、导出一张 SVG。

## 5. 边界（要主动说明）

- 完整版的游戏和数字人使用自带演示词库，不读取主应用数据库；它演示“还能怎么做”，不是学生真实作答。
- 完整版“分层练习”“学情看板”是演示数据，不能当本班统计；本班真实统计只在主应用“结果与日志”。
- 数字人只有在配置 `DEEPSEEK_API_KEY`（或根目录 `config.json`）后才走真实模型。
- 工作坊背包存在浏览器里，换电脑要导出备份；主应用课例与作答在 SQLite 里。
