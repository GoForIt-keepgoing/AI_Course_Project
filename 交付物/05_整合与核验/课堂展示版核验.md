# Animals 课堂展示版核验

## 素材与使用范围

| 来源 | 本版用途 |
| --- | --- |
| 课程综合说明第 2–3、7、9 页 | 三年级 Animals、四个目标词、问答句型和连续答辩要求 |
| 小学英语 AI 助教-完整版 | 复用连词成句、单词配对、记忆翻牌、打地鼠、跳跳岛和 Lily 动画对话引擎，新增同课例素材配置 |
| dist(1) | 检查解包目录和 ZIP，包含工作坊与英语冒险乐园。按确认方案使用完整版的 Lily。 |
| 既有 AI4En 答辩版 | 复用本机工作台、教学工作坊、SQLite 虚拟班级和 Animals 课例材料。 |

课堂版题库为内置示范材料。游戏积分和 Lily 句型匹配结果用于活动即时反馈，教师可在工作台另行记录课堂观察。

## 课程要求如何展示

| 课程项 | 展示位置 |
| --- | --- |
| R1 教学设计 | Animals → 教案备课，现场改一处，保存、重开并审核。 |
| R2 练习支持 | 练习与小测，比较同一道表达题的句架和关键词。 |
| R3 过程反馈 | 发布、学生提交、教师确认、学生订正，教师端对照原作和订正。 |
| R4 命题评价 | 课例包内七题学生卷、独立答案页、表达题评价要点。 |
| R5 资源活动 | 六页可编辑课件、词卡任务卡、教师端可编辑配对和排序。投屏页另有原版游戏与 Lily 问答。 |
| 教师培训与答辩 | 应用内使用指南、60 分钟培训资料、10 页 HTML 答辩及 [8 分钟脚本](../04_答辩材料/Animals课堂展示脚本.md)。 |

## 验证边界

演示使用虚拟班级与预置教学材料。Lily 的 Animals 场景使用规则匹配完整句型。麦克风和英语语音受浏览器、语音包与授权影响。真实模型及真实课堂试用需要另行验证。
